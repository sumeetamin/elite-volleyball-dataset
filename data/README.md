# Included real data

silver/mendeley_mens_worldcup_matches.csv contains 706 source records for the men's FIVB Volleyball World Cup editions listed in the CC BY 4.0 Mendeley dataset (1965–2019, intermittent). From 2000 onward this source contributes only 330 records: 66 each in 2003, 2007, 2011, 2015, and 2019. It contains no records from 2020 onward and is not a league-wide dataset.

The publisher's CSV headers are inconsistent with the row values. The importer preserves numeric source fields as unverified strings, does not interpret them as set scores, and uses only the publisher's explicit winner field as the match outcome. Dates and set-by-set scores are unavailable. This data can support limited match-outcome history, not rally, box-score, rotation, point-total, or set-score features.

Attribution: Thaksheel Alleck, Tommaso Giovannelli, Luis Nunes Vicente, Roman Mitchell, and Ori Remen (2024), “Match Score Dataset for Team Ball Sports”, Mendeley Data, Version 2, DOI: 10.17632/2pt4vmyf27.2, CC BY 4.0. Source page: https://data.mendeley.com/datasets/2pt4vmyf27/2

The accompanying coverage CSV lists every year 2000 through the run year and marks years absent from this source as no_records_in_source; that label does not claim there were no matches.
