# Historical match dataset: 2000–2026

This repository combines three sources with different scopes. It is a sourced compilation, not a complete census of world volleyball. Counts below describe records actually returned/imported; they do not imply that absent years had no matches.

Generated `data/` files are gitignored by default. Unless explicitly listed as tracked files, the tables described below refer to local pipeline outputs and are not published in this public repository.

The repository publishes a point-in-time denominator/coverage audit snapshot at [`reports/coverage_audit_2026-11-06.csv`](../reports/coverage_audit_2026-11-06.csv). It reflects 274 competition-season editions in the scope ledger; 22 have verified official denominators and observed counts, and all 22 meet the 80% threshold (2,841/2,853 = 99.58%). This is only the set of audited slices, not full coverage of every selected competition from 2000 onward. The denominator-verified set includes VNL 2021 men and women at 124/124 each. VNL 2020 men and women are explicitly marked cancelled from an official source and are not treated as zero-match or missing seasons. Rows marked `source_not_collected`, `zero_records_in_available_file`, or with an unknown denominator must not be treated as complete seasons.

## Included data

- `silver/fivb_vis_matches.csv`: 29,211 FIVB VIS match records dated 2000–2026, queried one calendar year at a time on 2026-11-05 UTC. This includes international matches and future/scheduled fixtures exposed by the public service; use `status` and set score fields to select completed outcomes. FIVB returned zero matches for 2000–2005. Per-year response counts, timestamps and hashes are in `coverage_fivb_vis.csv`.
- In the scope snapshot, FIVB VIS contributes 4,524 completed results matched to 40 men's World League/VNL and women's World Grand Prix/VNL editions from 2006–2026. Event names must match the appropriate division and edition year; qualification events and test-only placeholders are excluded. The source provides no counted results for 2000–2005 or the cancelled 2020 VNL edition. Annual expected-match denominators remain unknown, so no completeness percentages are claimed.
- `silver/fivb_vis_sets.csv`: one row per FIVB set whose two point values are present. This is derived from the match file and carries the original source record identifiers and response hashes.
- `silver/volleyball_australia_matches.csv`: all **2,327** game rows counted by the archive across 26 seasons, with **2,218 rows from 2000–2025**; it also contains 1998–1999 records. The snapshot has 2,267 declared winners, one declared draw, and 59 games with unknown outcomes. Exact match dates are generally unavailable; `round_heading` preserves archive context. 2020 and 2021 have no listed games. The archive itself says some seasons are incomplete. See `coverage_volleyball_australia.csv`.
- `silver/mendeley_mens_worldcup_matches.csv`: 706 records from intermittent men's FIVB World Cup editions 1965–2019. From 2000 it contributes 330 records in 2003, 2007, 2011, 2015 and 2019. The source's numeric columns are ambiguous, so only the explicit winner is interpreted.
- `silver/ncaa_matches.csv`: 108,245 NCAA match summaries covering women’s D-I matches from 2018–2025, plus women’s D-II/D-III and men’s D-I/D-III from 2020–2024. These include 2020–2024 matches (and scheduled/cancelled rows where the source lists them); source-row perspectives are grouped by season, date and team pair. `coverage_ncaa.csv` lists the exact available slices.
- `silver/ncaa_team_match_stats.csv`: 183,221 team-perspective rows with team box-score statistics (kills, errors, attacks, assists, digs, blocks, etc.) for the same NCAA coverage. These are a different data grain from the match summary and must not be added to match totals. 2018–2019 are one record per listed match in the upstream women's D-I archive; 2020–2024 team-perspective files can contain both sides of the same match. The upstream 2025 women's D-I file is explicitly reported as incomplete; don't treat its 5,068 grouped rows as a season census.
- `silver/cev_champions_league_matches.csv`: 297 CEV Champions League matches from official archived men's and women's competition pages, dated 2000–2005. The 44-row coverage log records season/phase requests and response hashes. The 2000/01 census is 60/60 per gender: 48 Main Phase, 8 CEV-labeled “4th Final,” and 4 Final Four results, deduplicated by official match ID. Other seasons remain partial. This is not all European volleyball.
- `silver/plusliga_m_2024_25.csv`: 240 Polish PlusLiga men's regular-season outcomes (official match IDs 001–240) from the league's 2024/25 schedule/results PDF; playoffs excluded. The extracted source table contains dates for 176/240 rows (73.33%); date-missing values stay blank. Set-point cells were omitted because the PDF text layer has contradictory/incomplete set details; the match result field is retained.
- `silver/cbv_superliga_matches.csv`: 2,353 Brazilian Superliga men/women match records, including 2017/18–2024/25. This includes regular-season and separately tagged playoff rows; 2,101/2,113 regular-season fixtures have completed results (99.43%). Twelve unscored rows remain `unknown`. The season page hashes and per-division coverage are recorded in `coverage/cbv_seasons.csv`.

The counts overlap between sources. Do not sum them as unique global games; deduplication across differently scoped competitions and providers is not asserted. Team IDs are provider-specific and are not globally reconciled. FIVB set rows are available only where the service returned both teams' set points. NCAA rows add team box-score aggregates but not the rally feed, rotations or player-level history. Historical bookmaker odds are not supplied by this compilation.

## Selected-league coverage status

Eighteen selected competition-season slices currently have verified denominators and all exceed 80%: Italian SuperLega men 2024/25 **132/132**, Polish PlusLiga men 2024/25 **240/240**, and Brazilian Superliga men/women 2017/18–2024/25 **2,101/2,113** in aggregate across 16 slices. Detailed CBV rates and raw-page hashes are in the local generated file `data/coverage/cbv_seasons.csv`; the checked-in `config/competition_seasons.csv` publishes source URLs and denominators. Many in-scope seasons from 2000 remain uncollected or unverified, so the overall selected-league target is not met. Assess the 80% goal per competition-season, not by pooling large unrelated datasets.

## Source, rights and limits

FIVB VIS public API documentation: [service overview](https://www.fivb.org/VisSDK/VisWebService/Introduction.html), [request protocol](https://www.fivb.org/VisSDK/VisWebService/Requests.html), [match list](https://www.fivb.org/VisSDK/VisWebService/GetVolleyMatchList.html), and [match fields](https://www.fivb.org/VisSDK/VisWebService/VolleyMatch.html). Public access does not establish a blanket redistribution license; retain provenance and check applicable terms before republishing elsewhere.

Australian historical archive: [Volleyball Australia results archive](https://superleague.volleyball.org.au/info/history/results-archive-1998-2022/). It states that seasons are incomplete and team names are historical. The page does not declare an open-data license; redistribution rights have not been confirmed, so generated records are not included in this public Git repository.

Brazilian CBV Data Project: [official competition index](https://cbv-web.dataproject.com/MainHome.aspx). Pages provide match IDs, fixtures and results for the imported seasons, but an open-data redistribution license was not identified. The normalized results and raw HTML snapshots remain local and are not included in this public Git repository pending terms review.

Mendeley attribution: Thaksheel Alleck, Tommaso Giovannelli, Luis Nunes Vicente, Roman Mitchell, and Ori Remen (2024), “Match Score Dataset for Team Ball Sports”, Version 2, DOI 10.17632/2pt4vmyf27.2, CC BY 4.0. [Dataset](https://data.mendeley.com/datasets/2pt4vmyf27/2).

NCAA data references: [ncaavolleyballr's archived CSV files](https://jeffreyrstevens.github.io/ncaavolleyballr/articles/data.html) and [download archive](https://github.com/JeffreyRStevens/ncaavolleyballr/tree/main/data-csv); [2018–2021 women’s archive and MIT-licensed scraper](https://github.com/mattwaite/NCAAWomensVolleyballData). The underlying records are NCAA statistics submitted by participating institutions; the upstream scraper/data repositories do not establish NCAA's blanket redistribution terms. The 2025 CSV has a maintainer issue noting partial coverage: [upstream report](https://github.com/JeffreyRStevens/ncaavolleyballr/issues/24).

CEV references: [men's Champions League history](https://www-old.cev.eu/Competition-Area/History.aspx?ID=70) and [women's Champions League history](https://www-old.cev.eu/Competition-Area/History.aspx?ID=73). The results are from public official pages, but an open-data redistribution license was not identified; check CEV terms before republishing the records.

## Rebuild / update

From the repository root, run `volley-data backfill-fivb --from-year 2000 --to-year 2026` to query FIVB and regenerate the set table; run `volley-data import-australia` to re-import the downloaded archive; run `volley-data import-ncaa` to rebuild the NCAA CSVs from `data/bronze/ncaa`; run `volley-data import-cev --from-year 2000 --to-year 2005` to backfill historical phase pages. For a full archived CEV LegList page, run `volley-data import-cev-leglist --source data/bronze/cev_cl_2000_01_men_leglist.html --competition-id 70 --gender M --season-name "2000/01 EUROPEAN CHAMPIONS LEAGUE" --source-url "https://www-old.cev.eu/Competition-Area/CompetitionView.aspx?CID=0&ID=70&PID=0&type=LegList"` (use ID 73, gender W, and the women's season label for women). It merges by official match ID, preserving phase, source URL and source-page hash. FIVB historical query results can change; each raw response is archived locally by the adapter and hashed in the coverage file. Coverage starts at 2000 by design even when a source provides no records for a year.
